# Weather Diary

Автор: Аристов Матвей

Описание: Программа позволяет добавлять, фильтровать и сохранять записи о погоде. В интерфейсе можно вводить дату, температуру, описание погоды и наличие осадков. Данные сохраняются в JSON и могут быть загружены позже.

Как запустить:  
- Установите Python 3.  
- Установите библиотеку tkcalendar (`pip install tkcalendar`).  
- Запустите скрипт `weather_diary.py`.

Примеры использования:  
- Ввод данных о погоде и добавление записи.  
- Фильтрация по дате и температуре.  
- Сохранение и загрузка данных.
